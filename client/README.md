# Client (Vite + React + Tailwind)

Quick start:

1. Install dependencies

```bash
cd client
npm install
```

2. Run dev server

```bash
npm run dev
```

Pages available:
- `/` Landing
- `/login` Login
- `/signup` Signup
- `/profile` Profile
- `/home` Home

This is a minimal scaffold. Hook the forms to your backend API endpoints (server) for real authentication.
